Phase 2's shadow control has a subtle but real flaw in what it's compared against

Look closely at the described output: "Evaluates the shadow control on validation" and compares it to "the original Frozen v1... on validation." But the whole point of a shadow control is to isolate one variable — and right now it's only half-isolated. Here's the gap: the shadow control gets more rounds, but is it evaluated using the same validation set the real drift-adapted comparison will eventually use? If yes, good. But the plan never mentions running the shadow control against the actual future drift-adapted ensemble side-by-side — it only compares shadow-vs-original-frozen-v1. That answers "does more training help at all" but not the real question, which is "when we eventually show recovery-after-drift, could that recovery be explained by rounds alone instead of drift-awareness." You need three numbers side by side, not two: original frozen v1, rounds-matched shadow (no drift exposure), and the eventual drift-adapted version — all evaluated identically on validation. Right now the plan only builds the first two. Flag this explicitly so the shadow control's output is actually usable later when you build the real recovery comparison, rather than needing to be redone.
